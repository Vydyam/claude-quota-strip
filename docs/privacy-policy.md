# Privacy Policy — Claude Quota Strip

**Last updated: August 1, 2026**

## What we collect
Claude Quota Strip collects **nothing**. No personal data, no usage data, no analytics, no telemetry.

## How it works
The extension reads session and weekly usage data from claude.ai's own API responses (the `message_limit` SSE event) and displays it locally in your browser. This data never leaves your device.

## Data storage
All data is stored locally using `chrome.storage.local`. It is never transmitted to any external server.

## Permissions used
- **storage** — saves session turn counts locally in your browser
- **tabs** — detects when you are on claude.ai

## Third parties
We do not share any data with third parties. There are no third-party analytics, tracking scripts, or external API calls.

## Contact
For questions, open an issue at https://github.com/Vydyam/claude-quota-strip

## Changes
Any changes to this policy will be committed to this repository with a clear changelog entry.
